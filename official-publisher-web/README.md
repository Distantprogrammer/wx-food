# 今天做什么菜 · 公众号发文台

独立的 Node.js + Express + EJS + SQLite 小网页。沿用项目根目录 `data/recipes.json`，不修改原小程序与云函数。默认仅监听本机 `127.0.0.1:3210`，管理员密码登录。

## 功能

- 按菜品 ID 升序自动选择尚未使用的菜谱，每天自动发表一篇；也可指定今天自动发表的菜品。
- 手动发表不限当天篇数。已经发表过的菜可以再手动发，提交前会要求确认。自动任务不会重发已有记录的菜。
- 用下拉选择菜品，已发表的菜在选项右侧标出。预览页可以修改标题、摘要和正文，再存草稿、更新或发表。提交微信时会显示加载状态。
- 四套文章模板可切换：家常经典、清新手账、一页速做、暖心食记。工作台设置自动发表的默认模板；单篇在预览页切换后再创建草稿或发表。已存草稿可以更换模板后更新，也可以删除后重做。发表记录显示所用模板。
- 北京时间每天 18:00 自动发表，页面可改成其他整点。当天稍晚启动会补发当天；不会补发往日。
- 菜品照片优先从项目根目录 `images/` 读取；缺失时使用通用品牌封面。真实小程序码已打包到 `public/qr.jpg`。

文章是**发表**，不会向公众号粉丝群发通知。发布依赖公众号具备草稿、素材上传和发表接口权限。

## 在这台 Windows 电脑启动

1. 安装 Node.js 22.13 或更新版本（当前电脑的 Node 22.21 可用）。在本目录执行 `npm ci`。数据库使用 Node 自带的 SQLite 接口，无需安装 SQLite 原生扩展；Node 22 首次运行可能显示一条 SQLite 实验性提示，不影响使用。
2. 复制 `.env.example` 为 `.env`，设置至少 12 位的 `ADMIN_PASSWORD`、至少 32 位随机字符串的 `SESSION_SECRET`、公众号的 `OFFICIAL_APP_ID`、`OFFICIAL_APP_SECRET`。不要把 `.env` 提交到 Git。先前在聊天中出现过的 AppSecret 建议在公众号后台重置后再使用。
3. 在公众号后台确认接口权限，并把**这台电脑的公网出口 IPv4** 加入公众号 IP 白名单。微信验证的是公网出口 IP，不是 `127.0.0.1` 或家庭路由器内网 IP。若运营商改变公网 IP，需要更新白名单。
4. 在 **Windows 文件资源管理器中双击 `start.cmd`**；也可以在 PowerShell 中运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\My Project\today-food\wx-food\official-publisher-web\start.ps1"`。点击文档里的文件名只会打开文件，不会执行。启动后打开 <http://127.0.0.1:3210>，登录后先预览文章。自动发表开关默认关闭；确认手动草稿、发表和状态查询都成功后再开启。运行期间请保持命令窗口开启，可以最小化。
5. 需要每天无人值守时，让电脑在 18:00 保持开机、联网，并让本程序持续运行。可使用 Windows 任务计划程序，在用户登录时执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\My Project\today-food\wx-food\official-publisher-web\start.ps1"`。请在本机任务计划程序内创建此任务；不要创建第二个同时运行的实例。

`storage/publisher.sqlite` 是发表记录和设置，定期备份该文件；运行时 SQLite WAL 模式还可能有 `-wal` 和 `-shm` 文件，建议停掉程序后复制备份。不要删除该数据库，否则已使用 ID 的去重记录会丢失。
首次使用新版程序时会自动给旧数据库增加模板字段，旧文章记录标为「家常经典」；现有发表记录不会删除。

默认只允许这台电脑访问网页。如果要从其他设备访问，请先配置 HTTPS 反向代理，再更改 `.env` 中的 `HOST`；不要直接把 HTTP 端口暴露到公网。

## 安全与故障状态

- `.env` 保存密钥、只供本地 Node 进程使用。网页登录 Cookie 有签名和有效期，写操作校验 CSRF，网页默认仅监听回环地址。
- 微信明确返回错误码时，已创建的草稿保留，可修正配置后重试发表。网络超时可能已经被微信受理，会标为“需核对”，不会自动重复提交。
- 缺少本地菜品照片不阻止发布，会用通用封面。可在 `COVER_IMAGE_DIR` 指定另一个本地照片目录。
- 18:00 定时任务需要本机运行且公众号白名单中的公网 IP 有效。该方案不需要升级云开发套餐，也不需要独立云服务器。

## 数据与技术

主数据：`../data/recipes.json`。数据库：`storage/publisher.sqlite`。Node 依赖：Express、EJS、dotenv；SQLite 使用 Node 内置模块。微信接口：稳定版 access_token、上传封面和正文图片、新增草稿、更新草稿、删除草稿、提交发表、查询发表状态。

本地检查：`npm test`。测试使用 SQLite 内存数据库，不会调用公众号接口。
